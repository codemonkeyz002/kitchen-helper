# Kitchen Helper

A lightweight kitchen page for an old iPad (iOS 12): recipes with serving scaling and step-by-step cook mode, multiple timers with alarms, and unit/oven conversions.

Live at: https://codemonkeyz002.github.io/kitchen-helper/

- `index.html` – the app (plain ES5 JavaScript so old Safari can run it)
- `recipes.js` – the recipe book. Add recipes here; the iPad picks them up automatically.
