# Kitchen Helper

A personal kitchen page for an old iPad (iOS 12): recipes with serving scaling and step-by-step cook mode, timers with alarms, and unit/oven conversions.

- `index.html` - the app (plain ES5 JavaScript so old Safari can run it)
- `recipes.js` - the family recipe book. Methods are rewritten in our own words; original sources are credited in each recipe's notes.

This is a personal project and isn't intended for public use.
